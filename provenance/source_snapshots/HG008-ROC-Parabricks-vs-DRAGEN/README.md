# HG008-ROC-Parabricks-vs-DRAGEN

Reproducible RTG Tools benchmarking workflow used to compare a PASS-filtered GPU-derived somatic call set against the Cancer GIAB DRAGEN hard-filtered somatic baseline for **HG008**.

---

## Overview

This repository contains the scripts used to reproduce the **RTG Tools benchmarking workflow** applied in our analysis of the Cancer Genome in a Bottle (Cancer GIAB) HG008 tumor–normal dataset.

The workflow is focused on the **benchmarking stage only**. It does **not** reproduce the full upstream variant-calling pipeline. Instead, it starts from:

- a **baseline somatic VCF** generated with **DRAGEN**, and
- a **PASS-filtered somatic calls VCF** generated by the GPU-based pipeline and prepared for RTG score-based benchmarking.

The pipeline performs:

1. conversion of the reference genome from FASTA to **RTG Sequence Data Format (SDF)**;
2. addition of a dedicated **`INFO.RTG_SCORE`** field to the calls VCF;
3. haplotype-aware benchmarking with **`rtg vcfeval`** in **annotate mode**;
4. generation of ROC-style outputs using **`rtg vcf2rocplot`** and **`rtg rocplot`**.

---

## Benchmarking design

The final working comparison used:

- **Baseline VCF:** Cancer GIAB DRAGEN hard-filtered somatic VCF  
- **Calls VCF:** PASS-filtered GPU-derived somatic VCF prepared for RTG scoring
- **Reference genome:** GRCh38 FASTA converted to RTG SDF
- **Sample mapping:** `HG008-T-mosaic,somatico`
- **ROC score field:** `INFO.RTG_SCORE`
- **Score source:** copied from the original caller-specific confidence metric (e.g. `TLOD`)

This design enables **haplotype-aware comparison** and **score-based threshold exploration** using RTG Tools.

## Repository contents

### Scripts

- `01_make_reference_sdf.sh`  
  Converts the GRCh38 reference FASTA into RTG SDF format.

- `02_add_rtg_score_to_calls_vcf.sh`  
  Copies the original caller score into `INFO.RTG_SCORE` and creates the RTG-ready calls VCF.

- `03_run_vcfeval_annotate.sh`  
  Runs `rtg vcfeval` in annotate mode to compare the baseline and calls VCFs.

- `04_run_vcf2rocplot_and_rocplot.sh`  
  Generates ROC-style tabular outputs and the default RTG ROC plot.

## Workflow summary

The benchmarking workflow follows this sequence:

```text
Reference FASTA
   └── 01_make_reference_sdf.sh
         └── ref_sdf_rtg/

Calls VCF
   └── 02_add_rtg_score_to_calls_vcf.sh
         └── PASS_RTG.vcf.gz

Baseline VCF + PASS_RTG.vcf.gz + ref_sdf_rtg/
   └── 03_run_vcfeval_annotate.sh
         ├── baseline.vcf.gz
         ├── calls.vcf.gz
         ├── summary.txt
         └── vcfeval.log

baseline.vcf.gz + calls.vcf.gz
   └── 04_run_vcf2rocplot_and_rocplot.sh
         ├── rocdata/weighted_roc.tsv.gz
         ├── rocdata/summary.txt
         ├── rocdata/vcf2rocplot.log
         └── roc.png
