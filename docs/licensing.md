# Licensing

The maintainer requested retention of a non-commercial policy for new BRISANCE material. The root [LICENSE](../LICENSE) implements that policy. It is a custom non-commercial license; this repository is not described as unrestricted open-source software.

Historical source copies keep their original notices:

| Source | Preserved terms |
| --- | --- |
| Parabricks scripts | Original `LICENSE_Non-Commercial` retained in the source snapshot |
| CPU comparator | Original `LICENSE` permits use/modification/sharing without attribution; retained unchanged |
| BCFtools comparison and RTG repositories | No standalone license was present in the migrated snapshots; do not infer one from public visibility |
| New BRISANCE wrappers/documentation and Nextflow material | Root non-commercial license, unless a file specifies otherwise |

No original license is silently replaced. Any adapted copy of a historical script is identified separately from its preserved source. Third-party tool, container, database, data and dependency licenses are not granted or changed by this repository. Before a public release, confirm author/contributor rights and whether any additional notices are needed.
